## Barney Agent

**Русский** · [English](README.md)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![GitHub stars](https://img.shields.io/github/stars/sergey-show/barney?style=flat&logo=github)](https://github.com/sergey-show/barney/stargazers)

Саморазвивающийся агент.

Это экспериментальный проект. В основу легла концепция Карла Юнга — [Самость](https://ru.wikipedia.org/wiki/Самость).

![Схема самость](assets/images/image.jpg)

Имя **Barney** — в память о моей собаке.

Агент учится на собственном опыте — на задачах, которые получились, и на тех, что провалились.

Он запоминает этот опыт, может его переиспользовать и строить связи.

Работает как CLI или веб-портал.

## Зачем такая форма

![Агент](assets/images/visual_agent.jpg)

Почти всё «самообучение» устроено механистически. Агенту заранее пишут жёсткую роль («кто ты»). Если задача не получилась — он меняет свой код или динамический навык и крутит это по кругу. Такой агент не учится в человеческом смысле. Он не понимает причин неудачи — он подстраивается в надежде, что новая конфигурация сработает. Человек же, ошибаясь, не делает себе лоботомию.

Barney собран иначе. Существование предшествует сущности: сначала поступок, потом строка в Самости. Ядро держит одну схему хода — план, инструмент, сверка, ревью — и не даёт текущей задаче эту схему переписать. Вокруг ядра растёт новая обвязка: уже существующие навыки, свой инструмент если готового нет, записанные провалы (Тень), записанные пути которые сработали (свет).

Ревью смотрит, **получен ли запрошенный результат**, а не насколько уверенно написан текст. Упорство (хотеть продолжать) не равно удовлетворению (нравится результат).

Также агент следует четырём слоям обвязки вокруг модели.

| | |
|---|---|
| **Ограничить** | Песочница, бюджет, повтор того же вызова. Физически нельзя, а не «строго запрещено». |
| **Сообщить** | Закон хода, факты сессии, уроки, Самость. Код собирает, что видно модели на этом шаге. |
| **Проверить** | Ревью смотрит на результат (файл, запуск, секрет, URL), не на уверенный текст. |
| **Исправить** | Сменить семейство инструмента, записать урок. Не долбить тот же вызов. |

## Карта

Эти имена описывают рантайм. Это не заложенная роль, которую вставляют в системный промпт.

| | В рантайме |
|---|---|
| **Самость** | Характер в действии. Растёт из поступков. Её нельзя заменить целиком. |
| **Эго** | Этот ход: план, инструменты, сверка, ревью. Центр шага, не всей личности. |
| **Персона** | Видимый ответ. Маска, не центр. |
| **Тень** | Зафиксированные ошибки. Их не затирают, пока не переработают. |
| **Мотив / действие / операция** | Зачем сессия / что делаем сейчас / какой инструмент. |
| **Хотеть ≠ нравиться** | Продолжать — сменив путь, а не долбя тот же вызов. |
| **Сон** | В простое сырая Тень сжимается в несколько эвристик. |
| **Фрустрация** | Много провальных путей → стоп и запрос смены парадигмы, с именем застрявшей Тени. |
| **Всплытие Тени** | Похожие прошлые провалы поднимаются до акта (эмбеддинги). |
| **Проверенный навык** | Навык пишется только после сработавшего восстановления — не выдумывается посреди промаха. |
| **Сначала анализ, потом план** | Одна модель: что должно стать истиной, затем шаги, затем акт и ревью. |

| `house-redact` | PASS | PASS | FAIL | FAIL | **1** | **1** |

## Установка

Тело агента всегда в `~/.barney`. Ядро можно поставить тремя путями.

### npm

Нужен [Bun](https://bun.sh) ≥ 1.4.

```bash
bun add -g @encsch/barney
barney web
```

Либо `npm install -g @encsch/barney` — на `PATH` всё равно должен быть `bun` (скрипт запускается через него).

### Релиз с GitHub

Скачайте файл под свою платформу с
[Releases](https://github.com/sergey-show/barney/releases/latest):

| Файл | Платформа |
|---|---|
| `barney-darwin-arm64` | macOS Apple Silicon |
| `barney-darwin-x64` | macOS Intel |
| `barney-linux-x64` | Linux x64 |
| `barney-linux-arm64` | Linux ARM64 |
| `barney-windows-x64.exe` | Windows x64 |

```bash
curl -L -o barney https://github.com/sergey-show/barney/releases/latest/download/barney-darwin-arm64
chmod +x barney
./barney web
```

### Из исходников

Нужен [Bun](https://bun.sh) ≥ 1.4.

```bash
git clone https://github.com/sergey-show/barney.git
cd barney
bun install
bun run build:web
bun run web            # портал → http://127.0.0.1:7331
bun run cli
bun bin/barney run "задача"
```

Свой бинарник: `bun run build:bin` → `./dist/barney`.

## Первый запуск

Привяжите модель. Облачные ключи подхватываются при загрузке:

```bash
export ANTHROPIC_API_KEY=...     # или OPENAI_API_KEY, GROQ_API_KEY
barney providers add --name local --host http://127.0.0.1:11434/v1 --use
barney providers use local --model <id-из-/v1/models>
```

При первом старте экземпляр ещё не спроектирован. Инициализация по пунктам или коротко **`канон`**. После проектирования сущность пишется поступками.

## Команды

| | |
|---|---|
| `barney web` | веб-портал (`--port 7331`, `--host 127.0.0.1`) |
| `barney acp` | ACP v1-агент через stdio |
| `barney cli` | Интерактивная сессия |
| `barney run "<цель>"` | Один прогон |
| `barney providers ls` | Список провайдеров LLM |
| `barney providers add --name … --host …` | добавить OpenAI-совместимый endpoint |
| `barney providers use <id> --model …` | Привязать модель (план, акт, ревью) |
| `barney agents ls` | Экземпляры |

Интерактивный CLI использует ту же границу сессий, что и Web. Полный список
показывает `/help`; основные сценарии: `/new`, `/sessions [запрос]`,
`/open <id>`, `/memory [запрос]`, `/note <ключ>`, `/work`, `/status`,
`/continue`, `/retry`. Ctrl+C останавливает активный шаг, не закрывая CLI.

## ACP

Barney даёт IDE тот же локальный жизненный цикл сессии через стабильный ACP v1.
Укажите в ACP-клиенте команду `barney-agent` либо запустите `barney acp` напрямую.
Транспорт — JSON-RPC 2.0 через stdio: сетевой слушатель и облачный сервис не
поднимаются. Первый запрос создаёт прогон Barney в `cwd` клиента, следующие
продолжают его, а отмена идёт тем же путём, что в Web и CLI.

## Тело

`~/.barney` — это тело. Git там — биография становления.

```
~/.barney/
  barney.sqlite      # агенты, прогоны, память
  self/              # Самость
  skills/ plugins/ mcp/
  worktrees/         # checkout на каждый прогон
```
