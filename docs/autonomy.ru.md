# Закон автономии

**Русский** · [English](autonomy.md)

Самообучение — ещё не автономия. Автономии нужна **узкая повестка**, из которой можно начать работу без запроса оператора.

> Пункт повестки пишут редко (из повторных PE/backlog-дыр),  
> в простое поднимают как самостоятельный прогон,  
> проверяют маркерами ZPD-3,  
> иначе выбрасывают.

## Три слоя

| Слой | Что это | Откуда |
|---|---|---|
| **Дыра** | Повторный fail с `pe:1` или незакрытый backlog (≥2) | эпизоды и backlog |
| **Пункт повестки** | Локальный drill **ZPD-3** + причина | `proposeAgendaItem` |
| **Самопрогон** | `createRun` из простоя | `Kernel.tick` → `self_run` |

Код: `src/application/autonomy/agenda.ts`, простой в `idleTick.ts` / `Kernel.tick`.

## Ограничения

- Пока дизайн не запечатан — ни учёбы, ни самопрогона
- Нет самопрогона, пока открыта сессия оператора
- Пауза (cooldown) после самопрогона
- Лимит ожидающих пунктов; один класс за раз
- Drill — локальные файлы (`recovery-<class>.md` + `proof-*.py` / soft harness), не «весь мир»
- Из простоя по-прежнему нельзя первым писать оператору
- **Inner think не пишет повестку** (подсказки логируются как ignored)
- **Карта способностей — только self-model**, не источник agenda
- **Self-run done ≡ ZPD-3 proof**; иначе статус `dropped`

## Связь с опытом

Автономия без рабочего опыта бесполезна. Порядок:

1. Сначала прирост на жёстком переносе — [Опыт](experience.ru.md)
2. Потом повестка из реальных PE/backlog-дыр
3. Карантинный навык сдаёт экзамен тем же путём (recall+use → SkillsLock) — см. петлю навыка в законе опыта
4. Карта способностей + decay → self-model (pulse / web), не agenda
5. Самопрогоны только **ZPD-3**: `proof-<class>.py` печатает `ZPD_PROOF fail=1`, затем `ZPD_PROOF pass=1` (без маркеров Kernel дропает drill)

В dream idle допускается консолидация блоков **Learned** и строк правил (дедуп/сжатие). Иммунная база конституции выше `# Learned` моделью не переписывается.

## Порядок в простое

`seed_samost` → доска → сон → поглощение Тени → **inner_think** (если ждём wake) → **самопрогон** → учёба → **inner_think** (долгий idle)
