# MCP

**Русский** · [English](mcp.md)

MCP здесь — **локальный stdio-сервер в теле**, не hosted-коннектор и не облако настроек.

Barney говорит по MCP `2024-11-05` через stdio: `initialize` → `tools/list` → `tools/call`. Автостарта при boot нет. Сервер живёт до `mcp_stop` или до выхода Barney.

Если хватает навыка или UI, берите [плагин](plugins.ru.md). MCP — когда нужен внешний процесс, которого в ядре нет.

## Рецепт

Сохраняется как плагин:

```
~/.barney/plugins/<name>/
  plugin.json
  mcp.json
```

`mcp.json`:

```json
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-github"],
  "env": {
    "GITHUB_TOKEN": "..."
  }
}
```

`command` + `args` запускаются в **worktree сессии**. Env процесса — короткий allowlist (`PATH`, `HOME`, локаль, temp) плюс `env` из этого файла. Облачные ключи процесса Barney **не** пробрасываются, пока их не запишут в `env`.

Также находятся:

- Claude-стиль `.mcp.json` / `mcpServers` внутри бандла плагина
- legacy `~/.barney/mcp/<name>/mcp.json`

В Web у такого плагина бейдж **MCP**. Отдельной формы «Add MCP server» нет.

## Оператор

Положите папку выше или попросите Barney подключить. В сессии агент сделает `mcp_start` и `mcp_call`.

Имя — kebab-case (`github-docs`, `context7`).

## Агент

Barney может подключить MCP **сам** на полном ходе:

| Tool | Что делает |
|---|---|
| `mcp_list` | Рецепты на диске и какие серверы уже запущены |
| `mcp_write` | Сохранить `~/.barney/plugins/<name>/mcp.json` |
| `mcp_start` | Поднять процесс, handshake, список tools |
| `mcp_call` | Вызвать tool на запущенном сервере |
| `mcp_stop` | Погасить процесс; рецепт на диске остаётся |

Типичная петля:

1. `mcp_list` — не плодить рецепт, если он уже есть.
2. `mcp_write` — только если stdio-сервер действительно нужен.
3. `mcp_start` — прочитать список tools у сервера.
4. `mcp_call` с `server`, `tool` и JSON `arguments`.
5. `mcp_stop`, когда закончили.

После `mcp_write` MCP пинится на экземпляр (`kind: mcp`), в git тела уходит `become: mcp <name>`.

Если ход застрял, **не** выдумывать MCP из промаха. Сменить семейство инструментов и всё равно доставить результат. Новый MCP — решение тела, не обходной путь.

## Ограничения

- Таймаут MCP-запроса: 20 с.
- Вложенный специалист может стартовать/вызывать MCP, но не растит ядро.
- `mcp_write` — не то же самое, что карантин навыка: рецепт можно записать сразу. Если recovery вида «после этой семьи сработала та» — лучше проверенный skill.
