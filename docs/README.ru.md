# Документация

**Русский** · [English](README.md)

Как вокруг ядра растёт **тело** Barney: инструменты, плагины и MCP.

Ядро в `src/` текущая задача не переписывает. Новая способность живёт в `~/.barney`.

| Гайд | О чём |
|---|---|
| [Инструменты](tools.ru.md) | Встроенный протокол инструментов на каждом ходе |
| [Плагины](plugins.ru.md) | Навыки, UI и рецепты в `~/.barney/plugins` |
| [MCP](mcp.ru.md) | Локальные stdio-серверы, которые агент может сохранить, запустить и вызвать |
| [Опыт](experience.ru.md) | Закон памяти: редкая запись, обязательное вспоминание, жёсткий перенос |
| [Eval](evals.ru.md) | Как запускать four-hand, Harbor, юнит-тесты |
| [Доказательства](proof/README.md) | Отчёты four-hand |
| [Автономия](autonomy.ru.md) | Закон повестки: дыры → самопрогон в простое → тренировка |
| [Wake](wake.ru.md) | Отложенные задачи: слежение за процессом, время; без фонового мышления |
| [Пластичность](plasticity.ru.md) | Кортикальная пластика: реконсолидация, обрезка, сон, дуэль |
| [Constrain](constrain.ru.md) | OS-песочница + опциональный Docker |
| [SPI](spi.ru.md) | Провайдеры тела на стабильных портах ядра |
| IDE ACP | [`../extensions/`](../extensions/README.md) |

Для новой способности лучше **плагин или навык**. **MCP** — только когда нужен внешний stdio-сервер.

К [корневому README](../README.ru.md).
