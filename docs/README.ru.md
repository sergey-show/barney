# Документация

**Русский** · [English](README.md)

Как вокруг ядра растёт **тело** Barney: инструменты, плагины и MCP.

Ядро в `src/` задача не переписывает. Новая способность живёт в `~/.barney`.

| Гайд | О чём |
|---|---|
| [Инструменты](tools.ru.md) | Встроенный протокол tools, который ядро даёт на каждом ходе |
| [Плагины](plugins.ru.md) | Навыки, UI и рецепты в `~/.barney/plugins` |
| [MCP](mcp.ru.md) | Локальные stdio-серверы, которые агент может сохранить, запустить и вызвать |

Для новой способности предпочитайте **плагин/навык**. **MCP** — когда нужен внешний stdio-сервер.

К [корневому README](../README.ru.md).
