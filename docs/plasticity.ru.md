# Закон пластичности

**Русский** · [English](plasticity.md)

Ядро — неизменный ствол. **Кортикальная пластичность** живёт в теле: веса, обрезка, сон, окружение.

> Связь усиливается, только если вспоминание изменило исход.  
> Неиспользованное слабеет.  
> Конфликт решается по пользе (дуэль).  
> Структуру ядра меняет только релиз человека.

## Механизмы

| Механизм | Поведение |
|---|---|
| **Польза по Хеббу** | сила + победы/переносы − провалы − возраст |
| **Реконсолидация** | при вспоминании: использовали и прошло ↑ · использовали и провал ↓ · проигнорировали — лёгкий спад |
| **Метапластика** | давление записи от фрустрации и дыр — в тишине меньше правил |
| **Обрезка** | низкая польза → в архив во время сна в простое |
| **Дуэль** | два навыка одного класса и режима → побеждает более полезный |
| **Окружение** | навык с чужим env в вспоминание не попадает |
| **Разморозка** | замороженный навык с серией провалов → снова «проверенный» |

Код: `src/application/plasticity/plasticity.ts`  
В простое: `plastic_sleep` (после сна, до поглощения Тени / самопрогона / учёбы).

## Связь с другими законами
